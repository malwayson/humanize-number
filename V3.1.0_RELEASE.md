# 🎉 v3.1.0 Release Highlights

## What's New in v3.1.0

### 1. 🔌 Plugin System

Create and register custom format methods for any domain-specific units!

```typescript
import { registerPlugin, humanizeNumber } from "@malwayson/humanize-number";

// Register a custom plugin
registerPlugin({
  name: "seismic",
  formatMethod: "seismic",
  units: {
    metric: [{ value: 1, symbol: "M", name: "magnitude" }],
    imperial: [{ value: 1, symbol: "M", name: "magnitude" }],
  },
  defaultOptions: { precision: 1 },
});

// Use it!
humanizeNumber(7.5, "seismic"); // "7.5 M"
```

**6 Example Plugins Included:**

- 🌍 Seismic (earthquake magnitude)
- ☢️ Radiation (Sieverts, rem)
- ⛰️ Altitude (feet, meters)
- 🔊 Decibel (sound levels)
- 🧪 pH (acidity/alkalinity)
- 💡 Luminosity (lumens)

### 2. 💰 Enhanced Currency Formatting

Customize currency symbols and positioning!

```typescript
import { humanizeCurrency } from "@malwayson/humanize-number";

// Different currencies
humanizeCurrency(1500000, { currencySymbol: "€" }); // "€1.50 M"
humanizeCurrency(1500000, { currencySymbol: "£" }); // "£1.50 M"
humanizeCurrency(1500000, { currencySymbol: "¥" }); // "¥1.50 M"

// Position control
humanizeCurrency(2500000, {
  currencySymbol: "EUR",
  currencyPosition: "suffix",
}); // "2.50 M EUR"

// Real-world scenarios
humanizeCurrency(2500000000000, { currencySymbol: "$", precision: 1 }); // "$2.5 T"
```

## Quick Start

```bash
npm install @malwayson/humanize-number@3.1.0
```

```typescript
import {
  humanizeCurrency,
  registerPlugin,
  examplePlugins,
  humanizeNumber,
} from "@malwayson/humanize-number";

// Enhanced currency
humanizeCurrency(150000, { currencySymbol: "€" }); // "€150.00 K"

// Use example plugins
registerPlugin(examplePlugins.seismic);
humanizeNumber(6.8, "seismic"); // "6.8 M"

registerPlugin(examplePlugins.radiation);
humanizeNumber(0.001, "radiation"); // "1.00 mSv"
```
